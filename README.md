# Bitácora de Congas

Plataforma para llevar el control del estudio del lenguaje afrolatino en las congas: racha de práctica, recursos por referente, plan de estudio, bitácora de sesiones, metrónomo con claves de son y rumba, loops y pistas para tocar encima.

Se usa en: https://bitacoracongas.github.io/BitaCongas/

Los datos se guardan en el navegador de cada dispositivo; el botón «Respaldo» sirve para pasarlos de uno a otro.

Sonidos de percusión: Versilian Community Sample Library (VCSL), dominio público (CC0).
